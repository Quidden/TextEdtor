# TextEdtor v0.1.0

First public release of TextEdtor.

## Highlights

- Dark desktop UI with a purple accent theme.
- Plain-text editor for preparing and cleaning text.
- Blacklist to whitelist replacement rules saved locally.
- Cleanup options for leading spaces and repeated empty lines.
- Text splitting by the `=====` separator with copyable result blocks.
- Image paste/drop conversion to WebP, PNG, and JPEG.
- Converted image preview can be dragged from the app as a file.
- Live in-app log tab backed by `data/app.log`.

## Download

Download `TextEdtor-v0.1.0-windows.zip` from this release, extract it, and run `TextEdtor.exe`.

## Notes

- This is a portable Windows build, not a system installer.
- Runtime data is stored next to the app in `data/` and `images/`.
- Windows SmartScreen may warn about the app because the executable is not code-signed yet.
